# Included License Texts

These files are retained for source publication and copied into Windows folder
builds. Do not remove them from a binary distribution.

| File | Covers |
| --- | --- |
| `Apache-2.0.txt` | SAM2 ONNX model files and other components identified as Apache-2.0 |
| `GPL-3.0.txt` | GPL version 3 text incorporated by LGPL-3.0 |
| `LGPL-3.0.txt` | PySide6 Essentials and shiboken6 open-source distribution route |
| `NudeNet-AGPL-3.0.txt` | NudeNet v3 and the bundled NudeNet ONNX model notice |
| `NumPy-2.2.6.txt` | NumPy and notices included in the installed NumPy distribution |
| `ONNX-Runtime-1.28.0.txt` | ONNX Runtime |
| `ONNX-Runtime-ThirdPartyNotices-1.28.0.txt` | Third-party code bundled with ONNX Runtime |
| `OpenCV-4.12.0.txt` | OpenCV |
| `OpenCV-ThirdParty-4.12.0.txt` | Third-party code bundled with OpenCV |
| `Pillow-11.3.0.txt` | Pillow and its bundled notices |
| `PyInstaller-6.15.0.txt` | PyInstaller, including its bootloader exception |
| `Python-3.13.txt` | Python 3.13 |
| `SAMExporter-MIT.txt` | SAM Exporter reference implementation |
| `DeepGHS-Model-MIT-NOTICE.md` | DeepGHS model-card MIT declaration and attribution note |

`LICENSE` at the repository root contains the AGPL-3.0 license for Auto Mosaic.
The additional NudeNet copy is retained so a binary recipient can associate the
model with its upstream license independently.

The installed PySide6 wheels do not provide a complete static list covering all
third-party code in the Qt DLLs. Before a binary release, compare the included Qt
modules with Qt's current official third-party license list and add any applicable
notices here:

https://doc.qt.io/qt-6/licenses-used-in-qt.html
