# FY175AutoMosaic

Windows上でPNG/JPEG画像をまとめて確認し、検出した対象へモザイクまたは
ぼかしを適用するデスクトップアプリです。画像は外部へ送信されず、すべて
ローカルで処理されます。

## できること

- PNG/JPEG画像を複数まとめて、またはドラッグ＆ドロップで読み込み
- 実写／イラストを切り替え、対象を自動検出
- 検出範囲と処理後の画像を保存前にプレビュー
- 選択ブラシで検出マスクの不足部分を追加し、余分な部分を削除
- Shift+クリックによるAI領域選択と、Ctrl+Zによるマスク編集の取り消し
- モザイク／ぼかしの種類、強さ、検出しやすさを調整
- マスク閾値とマスク拡張で、自動マスクの範囲を調整
- モザイク／ぼかし処理した画像を指定フォルダへ保存
- 元画像の隣の `.fy` テキストファイルにマスクと設定を保存し、次回の読み込みで復元
- 自動処理から除外した画像名を、要手動対応メモとして管理
- エージェント向けのローカルHTTP APIから画像の読み込み・マスク編集・保存を操作

## 起動方法

### Windows配布版を使う場合

1. 配布されたZIPを展開します。
2. `FY175AutoMosaic`フォルダ内の`FY175AutoMosaic.exe`を起動します。

`FY175AutoMosaic.exe`だけを別の場所へ移動しないでください。モデルや動作に必要な
ファイルを含むため、展開した`FY175AutoMosaic`フォルダ全体をそのまま使用します。

### ソースコードから起動する場合

Python 3.13をインストールし、リポジトリを取得したフォルダでPowerShellを
開いて、次のコマンドを順番に実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\download_models.py
.\.venv\Scripts\python.exe -m auto_mosaic.app
```

`download_models.py`が必要なモデルを自動で`models`フォルダへ配置し、ファイルが
正しいかも確認します。ダウンロードにはインターネット接続と約170MB以上の
空き容量が必要です。

正常に配置されるファイルは次の4つです。

- `models/nudenet-320n.onnx`
- `models/anime-censor-detect-v1.0-n.onnx`
- `models/sam2_hiera_tiny.encoder.onnx`
- `models/sam2_hiera_tiny.decoder.onnx`

モデル不足のメッセージが表示された場合は、リポジトリ直下で
`.\.venv\Scripts\python.exe scripts\download_models.py`をもう一度実行してください。
モデルの出典とライセンスは`MODEL_LICENSES.md`に記載しています。

### エージェントから操作する場合

エージェント向けのローカルHTTP APIを内蔵しています。`--agent-api` を付けて起動し、
ルートURLへGETすると、操作一覧・引数・設定範囲・操作手順を取得できます。

配布版では、展開した `FY175AutoMosaic` フォルダでPowerShellを開いて起動します。

```powershell
.\FY175AutoMosaic.exe --agent-api
```

起動後、別のPowerShellから案内を取得できます。

```powershell
Invoke-RestMethod -Uri 'http://127.0.0.1:8765/' -Method Get
```

ソース版は `.\.venv\Scripts\python.exe -m auto_mosaic.app --agent-api` で起動します。
ポートを変える場合は `--agent-api 8766` のように指定します。通常起動ではAPIを開きません。
外部サービスやMCP登録は不要で、画像は外部へ送信されません。

エージェントには「`http://127.0.0.1:8765/` にGETし、返された操作一覧と手順に従って
画像を処理する」と伝えます。APIは画面と同じ画像リスト・設定・マスク編集状態を使います。

| リクエスト | 用途 |
| --- | --- |
| `GET /` | 操作一覧、引数、設定範囲、操作手順、アプリのPIDを取得 |
| `GET /state` | 選択画像、マスク、処理状態を確認 |
| `GET /preview?view=mask_overlay` | マスク範囲のプレビューを取得 |
| `POST /commands` | 画像の読み込み、設定変更、マスク編集、保存などを実行 |
| `GET /jobs/ID` | 非同期処理の完了・失敗を確認 |

`POST /commands` には `{"operation":"操作名","arguments":{...}}` を送ります。
非同期処理は返されたジョブが `succeeded` または `failed` になるまで確認してください。
`.fy` の保存・復元も操作でき、終了には `app.shutdown` を使います。
具体的な操作と座標の扱いは、同梱の [AGENT_INTERFACE.md](AGENT_INTERFACE.md) を参照してください。


## 基本的な使い方

1. 処理する画像を読み込みます。
2. 画像に合わせて「実写」または「イラスト」を選びます。
3. 検出対象と検出閾値を指定します。
4. プレビューで検出範囲と処理結果を確認します。
   どの表示でもマウスホイールで画像を段階的に拡大・縮小できます。画像上では
   カーソル位置、それ以外では画像中央が基準になり、初期表示より小さくはなりません。
5. 必要なら、どのプレビュー表示からでも「マスクを編集」を開始できます。
   詳しい操作は下の「マスク編集の操作」を参照してください。
6. 出力先を選び、「表示中の1枚を処理して保存」または「すべて処理して保存」で保存します。

初回の画像表示時はモデルの読み込みに少し時間がかかることがあります。

### マスク編集の操作

「マスクを編集」を押してから、画像上で次の操作を行います。「元画像」「処理結果」から
編集を開始すると「マスク範囲」表示へ切り替わり、検出矩形とラベルは非表示になります。

| 操作 | 動作 |
| --- | --- |
| ドラッグ | ブラシでマスク範囲を追加 |
| Alt+ドラッグ | ブラシでマスク範囲を削除 |
| Shift+クリック | クリック位置のAI推定領域を追加 |
| Ctrl+Shift+クリック | クリック位置のAI推定領域を削除 |
| Ctrl+Z | 直前のマスク編集を取り消し |
| マウスホイール | カーソル位置を基準に段階的に拡大・縮小 |

AI領域選択は現在の「マスク閾値」を使い、クリック位置につながる部分だけを選びます。
色差による選択ではありません。初回のクリックでは画像の解析に時間がかかる場合があります。
選択範囲が合わない場合は閾値を調整して再度クリックするか、ブラシで補います。

Ctrl+Zでは、1ドラッグまたは1回の領域選択が1操作です。履歴はAPI操作と共通で
最大20操作（圧縮マスク合計128 MiB以内）を保持し、保存・編集終了・画像切替で消去します。
編集中に「処理結果」へ切り替えても編集内容は保持されるため、仕上がりを確認してから保存できます。

編集したマスクは「表示中の1枚を処理して保存」でのみ使用され、画像を切り替えたり
リストから除去したりする際は、未保存の編集を破棄するか確認します。
編集内容を後で使う場合は「.fy保存」を有効にして保存してください。

### .fyファイルにマスクと設定を保存・復元する

`.fy` はマスク範囲と処理設定を記録するファイルです。画像そのものは含まず、
処理後の画像とは別に、**元画像の隣**へ保存します。

「処理後にリストから除去」の隣の「.fy保存」を有効にすると、処理して保存する際に、元画像と同じ
フォルダへ `画像.png.fy`（JPEGなら `画像.jpg.fy`）を保存します。一括処理も対象です。
既存の `.fy` は最新の内容で更新します。「処理せず保存」では `.fy` を保存しません。

例えば、`C:\images\sample.png` を読み込み、マスクを編集して「.fy保存」を有効にして
処理すると、`C:\images\sample.png.fy` が作成されます。次回は処理後の画像ではなく、
同じ元画像 `sample.png` を読み込むとマスクと設定を復元できます。

元画像を再び読み込むと、隣の `.fy` からマスク範囲と処理設定を自動復元します。
上部の「マスク復元」でも読み込み直せます。元画像の隣に対応する `.fy` があればすぐに復元し、
なければファイル選択画面を開きます。別の場所へ移した `.fy` も選択できますが、元画像は保存時と同じものが必要です。
未保存のマスク編集中は置き換え前に確認し、読み込みエラーやファイル選択のキャンセルでは編集内容を保持します。
モザイク／ぼかしの種類やサイズを変更してもマスク範囲を保持し、再解析せずに保存できます。
一括処理では保存済みのマスクと現在の画面の設定を使います。「この画像を再解析」を押すと
自動検出からやり直します。再解析や編集中の範囲を残す場合は、改めて `.fy` を保存してください。

`.fy` はUTF-8のJSONテキストで、画像寸法、元画像のSHA256、処理設定、正確なピクセル範囲を
連続区間の開始位置と長さで記録します。元画像が変わっていたりファイルが壊れていたりする場合は
エラーを表示し、保存済み範囲を黙って自動検出で置き換えません。移動時は元画像と `.fy` を一緒に移動してください。

### 検出対象は正しいのにマスク範囲が合わない場合

右側の「マスク閾値」と「マスク拡張」を調整し、「この画像を再解析」を押します。
「検出範囲」表示で輪郭を確認し、「処理結果」表示で仕上がりを確認してください。

- **マスク閾値**（初期値 `0.0`、範囲 `-10.0` ～ `10.0`）：各ピクセルをマスクへ含める判定値です。
  隣の領域を巻き込む場合は上げ、対象の一部しか選ばれない場合は下げて、まず `0.5` 刻みで試します。
  対象そのものの採否を決める「検出閾値」とは別の設定です。
- **マスク拡張**（初期値 `3 px`、範囲 `0` ～ `20 px`）：判定後の輪郭の周囲を広げる量です。
  元画像のピクセル単位です。周辺を巻き込む場合は `0 px` まで減らせます。
  細い隙間や凹みを埋める輪郭補正は拡張量から独立しており、`0 px` でも一定の強さで行います。
  `0 px` は輪郭補正後のマスクを周囲へ広げない設定です。突出部分を削る処理ではありません。

値を変えるだけでは表示中のマスクは変わりません。自動マスクには次の解析・保存処理から適用されます。
設定は実写／イラストと単一画像／一括処理で共通です。`.fy` に保存した設定は元画像の読み込み時に復元されます。
編集中もマスク閾値は変更でき、次のクリックによる領域選択に反映します。
マスク拡張は編集中に変更できません。クリックによる領域選択には拡張を適用せず、
編集したマスクの保存にも閾値や拡張を再適用しません。

閾値を変えると別の輪郭候補が選ばれることもあり、常に少しずつ広がる・狭まるとは限りません。
また、検出枠付近への制限と中心付近の領域だけを残す処理があるため、閾値だけでは補えない不足もあります。
「矩形補完」と表示された対象は輪郭候補が採用できず検出矩形で代用しており、マスク閾値や拡張による
輪郭調整は効きません。改善しない場合は「マスクを編集」で追加・削除してください。
