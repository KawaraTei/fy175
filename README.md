# FY175AutoMosaic

画像・動画の対象を自動検出し、モザイクまたはぼかしを適用するデスクトップアプリです。
画像は外部へ送信せず、すべてローカルで処理します。

**[最新版 1.1.1をダウンロード](https://github.com/KawaraTei/fy175/releases/tag/1.1.1)** — Windows CPU版。
macOS・NVIDIA GPUは[ソース版](docs/DEVELOPMENT.md)をご利用ください。

## できること

- PNG/JPEG画像の一括読み込み・自動検出・モザイク／ぼかし処理
- ブラシやShift+クリックのAI領域選択によるマスク修正、別のマスク候補への切り替え
- 処理結果のプレビューと、マスク・設定の保存／復元（`.fy`）
- PNG保存時の生成プロンプトやワークフロー等のテキストメタデータの保持
- PSD/CLIPのレイヤー別の加工・検出・表示切り替え、元のレイヤー形式での保存（β）
- 動画の自動検出、マスクの手動修正・区間補完、MP4出力、編集の保存／再開（β）

## 起動方法

### Windows配布版を使う

1. [リリースページ](https://github.com/KawaraTei/fy175/releases/tag/1.1.1)から `FY175AutoMosaic.zip` をダウンロードして展開します。
2. `FY175AutoMosaic` フォルダ内の `FY175AutoMosaic.exe` を起動します。

モデルと必要なファイルを同梱しています。EXEだけを移動せず、フォルダ全体をそのまま使用してください。
`ThirdPartySources.zip` はライセンスに基づくソース資料で、アプリの実行には不要です。

### ソース版・macOSで使う

- **Windows**：[Python 3.13でのセットアップ](docs/DEVELOPMENT.md#windowsのセットアップ)
- **NVIDIA GPU**：[GPUセットアップ](docs/DEVELOPMENT.md#nvidia-gpuで高速化する場合)（CUDA 13対応ドライバーが必要）
- **macOS**：[セットアップ・操作・アプリのビルド](MACOS.md)（Apple Silicon／Intel、CPU処理）

## 基本的な使い方

1. 「画像を追加」またはドラッグ＆ドロップでPNG/JPEGを読み込みます。
2. 「詳細設定」で「実写／イラスト」と検出対象を選び、必要に応じて再解析します。見出しを押すと設定を折り畳めます。
3. 「マスク範囲」と「処理結果」を切り替え、処理方法と強さを調整します。ホイールで拡大・縮小できます。
4. 範囲が合わない場合は「次のマスク候補」で切り替えるか、「マスクを編集」で修正します。
5. 出力先を選び、「表示中の1枚を処理して保存」または「すべて処理して保存」で保存します。

**手動編集したマスクは「表示中の1枚を処理して保存」で保存してください。**
「.fy保存」を有効にすると元画像の隣にマスクと設定を保存し、次回の読み込みで復元できます。
自動検出には誤検出と検出漏れがあるため、保存前に範囲を確認し、出力結果も目視で確認してください。

### マスク編集の主な操作

| 操作 | 動作 |
| --- | --- |
| ドラッグ／Alt+ドラッグ | ブラシで追加／削除 |
| Shift+クリック／Ctrl+Shift+クリック | AIが推定した領域を追加／削除 |
| Ctrl+Z | 直前の編集やマスク候補の切り替えを取り消し |

MacではCtrlはCmd、AltはOptionです。「次のマスク候補」は画像モード専用です。

### レイヤー画像・動画

- **PSD/CLIP**：「レイヤー画像(β)」から開き、レイヤーごとに「加工」「検出」「表示」を指定します。
  マスクを修正して、統合画像または元のレイヤー形式で保存できます。
  PSDは8bit RGB、直接加工できるのはラスターレイヤーです。特殊な合成・効果は元ソフトと異なる場合があります。
- **動画**：「動画モード(β)」から開いて解析し、タイムラインで検出範囲を確認します。
  マスクの修正・区間補完後にMP4へ書き出せます。編集の保存／再開には `.fyvideo` を使います。

詳しい手順と形式ごとの制約は[操作ガイド](docs/USAGE.md)を参照してください。
